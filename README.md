# University Admissions — Rule 

Two tiny models on UCLA admissions:

1. **Points model (compensatory)** — add points for passing simple checks; admit if total points reach a set number.
2. **All-gates model (non-compensatory)** — admit only if all minimum standards pass.

## Run

```bash
python -m pip install -r requirements.txt
python run_experiment.py

After running, the results folder will appear containing all the metrics.
